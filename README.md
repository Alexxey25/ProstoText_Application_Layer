## О проекте

В рамках курсовой работы реализован прикладной уровень распределённой системы упрощения сложных научных и технических текстов.

Разработан веб-чат с входом по имени, вводом текста и загрузкой TXT-файлов. Запрос передаётся транспортному сервису по HTTP, а части упрощённого ответа поступают в браузер через SSE. Реализованы обработка ошибок, независимые пользовательские сессии и очистка истории при выходе.
